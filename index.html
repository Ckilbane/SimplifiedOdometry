SPOT: Simplified Pinpoint Odometry Tracker

SPOT is Phil Malone's Simplified Odometry rebuilt for the goBILDA Pinpoint. Your robot gets three simple moves, drive, strafe and turnTo, and each one measures what the robot actually did. You don't need a path-following library or a tuning marathon. It comes in OnBot Java for mecanum and StarterBot tank drive, and as custom Blocks for Blocks-only teams.

Get it onto the robot

These steps are the same for every version. You don't need Android Studio.

Download the files

Download the files for your version from the cards above onto a laptop.

Join the robot's Wi-Fi

Connect the laptop to the robot's network and open 192.168.43.1:8080 in a browser.

Upload in OnBot Java

Open the OnBot Java tab, click Upload Files and pick the downloaded .java files. They go in the teamcode folder.

Build Everything

Click the wrench and wait for Build SUCCESSFUL. Blocks teams then find Java Classes → SpotBlocks in the Blocks editor.

What SPOT changes

  • The Pinpoint replaces the dead-wheel encoder ports and the hub IMU.
  • Moves stay robot-relative after a turn, even though the Pinpoint reports field position.
  • Every Pinpoint call passes explicit units, as the SDK's built-in driver requires.
  • Blocks teams get the whole thing as custom blocks with plain-language error messages.

Status: compiled against stand-ins for the SDK classes. The Blocks version hasn't run on a robot yet. Please report what you find.
